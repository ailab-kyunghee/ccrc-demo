# ccrc-demo

1. vscode에서 frontend와 backend 폴더를 포함하고 있는 ccrc-demo 폴더를 열고 아래에 powershell을 두개 연다.


2. 백엔드 프로그램 실행

첫번째 powershell에서 다음의 명령어를 순서대로 입력한다.

cd C:\Users\user\Downloads\ccrc-demo\ccrc-demo\backend
python server.py

실행되면 powershell을 절대 끄지 말고 혹시라도 꺼졌으면 같은 과정으로 다시 실행시키면 된다.


3. 프론트엔드 프로그램 실행

두번째 powershell에서 다음의 명령어를 순서대로 입력한다.

cd C:\Users\user\Downloads\ccrc-demo\ccrc-demo\frontend
npm run serve

실행되면 powershell을 절대 끄지 말고 혹시라도 꺼졌으면 같은 과정으로 다시 실행시키면 된다.

4. Chrome을 켜서 http://localhost:8080/ 에 접속한다.
